# EnergyAutomation — User Guide: Introduction

## 1. Welcome to EnergyAutomation
**EnergyAutomation** is an enterprise industrial Energy Management System (EMS) desktop application designed and tailored for the **Savera MS** manufacturing facility.

The system automates the daily ingestion, verification, calculation, and reporting of factory electricity consumption received through automated NBSense monitoring emails.

---

## 2. Core Philosophy: CONFIGURE → AUTOMATE → OBSERVE → ANALYSE → ACT
EnergyAutomation is built on a single governing philosophy:
- **Configure**: Set your plant parameters, Excel workbook destination, and notification preferences once.
- **Automate**: The system checks for new daily EMS reports in the background on an automated schedule.
- **Observe**: Monitor live plant status badges, daily KPIs, and production zone health cards at a glance.
- **Analyse**: Examine meter-by-meter breakdowns, Day-over-Day variance, Month-to-Date (MTD) totals, and AI anomaly insights.
- **Act**: Identify excessive energy consumption, detect equipment running during idle hours, and optimize factory energy efficiency.

---

## 3. Dual-Mode Experience: Simple vs Engineer Mode
EnergyAutomation serves both technical plant engineers and non-technical managers:
- **👤 Simple Mode (Default)**: Designed for plant directors, general managers, and administrative personnel. Presents clean status cards, plain-language operational statuses, and high-level charts. Hides internal technical tracebacks and complex cell coordinates.
- **🛠 Engineer Mode**: Designed for electrical engineers and automation specialists. Displays raw JSON payloads, exact Excel cell coordinates (e.g. `C16:Q16`), parser diagnostics, execution durations, and full console event streams.

You can switch between modes at any time using the mode toggle button in the top-right header bar.
